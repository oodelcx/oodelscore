Playbooks

Standard guidance per issue type, so a manager isn't improvising a response from scratch.

Long wait time complaints

4 steps · used 34 times this quarter

  1. Acknowledge and apologise within 24h if contact info given
  2. Check if it's recurring (3+ mentions in 2 weeks) or one-off
  3. If recurring, escalate to regional ops for a staffing review
  4. Log resolution and expected fix date
Issues resolved ~2× faster when this is followed

Cleanliness complaint

3 steps · used 19 times this quarter

  1. Confirm time of day and area with the branch manager
  2. Check shift schedule for that window
  3. Log outcome and any schedule adjustment made
